# Tower Defence: Port & Extension

This repository features a **Tower Defence** game ported/developed/extended by **Michał Kukuczka** and **RK** as a rump-up into C # development for young men. 
The project is a comprehensive PC port and mobile extension of an existing title, rebuilt and enhanced to deliver a fresh gaming experience.

### Key Features
* **Faithful Port:** Recreates the core balance and feel of the original game.
* **Custom Extensions:** Introduces brand-new tower types, unique enemies, and upgraded mechanics.
* **Modernised UI:** Offers a cleaner, more intuitive user interface.

### Tech Stack
* **Engine:** Unity 2023.2 (Tech Stream)
